# 박요한 · 김세나 결혼예식 순서지

GitHub Pages에 바로 올릴 수 있는 정적 웹 순서지입니다.

## 구성

- `index.html`: 웹 순서지
- `assets/wedding-photo.jpg`: 웨딩 사진
- `assets/hymn-605.svg`: 찬송가 605장 가사 이미지
- `.nojekyll`: GitHub Pages용 설정 파일

## 게시 방법

이 폴더의 파일을 GitHub 저장소의 최상위에 올린 뒤, 저장소의 **Settings → Pages**에서 배포할 브랜치와 루트 폴더를 선택하면 됩니다.
